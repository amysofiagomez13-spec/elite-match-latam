ELITE MATCH LATAM — ARCHIVOS INICIALES

Contenido:
- index.html: estructura de la página de bienvenida.
- styles.css: diseño adaptable a celular y computador.
- app.js: selector de idioma y botones de demostración.

IDIOMAS:
Español (inicial), inglés, francés, portugués, alemán, chino simplificado y chino tradicional.

CÓMO PROBAR:
1. Descomprime el archivo ZIP.
2. Abre index.html en un navegador para ver la página inicial.
3. Para publicarla, sube estos tres archivos a un servicio de alojamiento web estático.

IMPORTANTE:
Esta es una maqueta funcional de la página de bienvenida. Los botones Crear cuenta e Iniciar sesión muestran un aviso de “próximamente”; todavía no hay registro real, base de datos, autenticación, membresías, chat ni llamadas. Esas funciones deberán desarrollarse y probarse antes de lanzar el servicio.

RESPALDO DE VIVE CARTAGENA:
Mantén Vive Cartagena en su carpeta/repositorio actual. Guarda una copia descargada por separado antes de iniciar Elite Match LatAm. No reemplaces ni borres los archivos de Vive Cartagena.
